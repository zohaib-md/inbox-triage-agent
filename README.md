# inbox-triage-agent

Inbox triage agent built with Google ADK + agents-cli — classifies emails and drafts replies, no auto-send.

> **Status: in progress**

## Overview
Automated support inbox triage system for a SaaS product. Takes inbound emails, classifies them (`urgent`, `needs_reply`, `fyi`, `spam`, or flags as `needs_human_review` if ambiguous), and prepares high-quality suggested reply drafts for human review.
